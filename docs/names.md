# Shaping — name candidates

Date: 2026-09-28. Every name below was checked against the npm registry on that day; "free" means the registry returned 404 for the unscoped name. Domains are reported as "resolves" or "no record", which is a hint about registration and not proof of availability. The full table of 50 names checked is in `names_full_check.md`.

## Recommendation

**Keep `shaping`.** It is free on npm, it names what the tool does whatever the genre, and it is already the word in use. Its weakness is that it is a common word: the `.com` and `.dev` domains resolve, and it is hard to search for. That matters for a product to be marketed and little for a tool and a library.

If a more distinctive name is wanted, the choice is between `umbraform` (cleanest record, leans toward shadows) and `turnery` (a real word for lathe work, leans toward turning).

## Note on scoped names

None of the shortlisted names needs a scope. If the package split is option B (a core and separate genre packages), the genre packages would be `shaping-genre-turned` and `shaping-genre-shadow-blocks`, or live under a scope; those names were not checked.
